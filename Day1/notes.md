## 🧠 What is Programming?

### **Basic Concept**
Programming is the process of writing instructions for a computer to perform specific tasks.

### **Definition**
Programming is writing instructions for a compiler to perform specific tasks.

### **Purpose**
- Automate tasks  
- Solve problems  
- Create systems and applications  

---

## 🔤 High-Level vs Low-Level Programming

### **Types of Programming Languages**

#### **1️⃣ High-Level Languages**
- Closer to human languages  
- Easy to read and write  
- Examples: **Java, Python**

#### **2️⃣ Low-Level Languages**
- Close to machine language  
- Hard to understand  
- Examples: **Assembly, Machine Code**

### **Translation Requirement**
High-level code must be **translated into low-level machine code** for execution.

---

## 🧮 What is Binary Code?

### **The Language of Computers**
- Binary uses only two digits: **0 and 1**  
- Represents **OFF (0)** and **ON (1)** states  
- All computer operations occur in binary  

### **Conversion**
High-level code → translated to binary → executed by the computer

---

## ⚙️ Compiler and Interpreter

### **Compiler**
- Translates the entire program into machine code **before** execution  

### **Interpreter**
- Translates code **line-by-line** during execution  

### **Java Uses Both**
1. Java compiler converts source code → **bytecode**  
2. JVM interprets bytecode and executes it  

---

## 📜 History of Java (Timeline)

### **Key Events**
- **1991** – Project started by James Gosling at Sun Microsystems under the name **OAK**  
- **1995** – Official release as **Java 1.0**, with the motto *“Write Once, Run Anywhere”*  
- **2010** – Oracle acquired Sun Microsystems and took over Java  
- **2014** – **Java 8** released (major update: Streams, Lambda Expressions, etc.)  
- **2025** – **Java 25** released (September 16, 2025)
